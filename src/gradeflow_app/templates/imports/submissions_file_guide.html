In Moodle 4.4 and earlier, both downloads are on View all submissions.
  • Ultra: in the Gradebook, open the test, then Download results, and choose .csv, By student and the attempts used for the grade
  • Original: in the Grade Center, open the test column's menu, then Download Results, and choose Comma, By User and Only Valid Attempts

Each question has several columns. Under Check rows and columns, mark only the answers as Answer.
  • Ultra: open the assignment's Submissions, then the ⋯ menu, Download all, Create ZIP File and Send. Download the zip from the link in your messages
  • Original: in the Grade Center, open the assignment column's menu, then Assignment File Download. Select all students, click Submit, then Download assignments now

Files are named with each student's username. For student IDs, download the gradebook (Ultra: Download grades, Original: Work Offline then Download) and add it under Map student IDs.
